# CTF Practice Checklist

Use this before and after a practice solve to keep the workflow consistent.

## Before solving

1. Create a fresh project for the challenge.
2. Record the challenge category and expected flag format.
3. Keep original challenge files unchanged.
4. Start with quick triage before deeper transforms.

## During solving

1. Review ranked findings and evidence before chasing weak candidates.
2. Save useful decoded or extracted artifacts in the project workspace.
3. Prefer reproducible transforms over one off manual edits.
4. If a path fails, record what was tested before switching approaches.

## After solving

1. Verify the final flag against the expected format.
2. Keep a short note of the successful solve chain.
3. Remove secrets, private competition files, and temporary artifacts before committing.
4. Run the local checks if solver code was changed.
